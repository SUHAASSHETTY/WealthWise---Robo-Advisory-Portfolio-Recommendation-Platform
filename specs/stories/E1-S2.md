## Description

Pure domain types and validation for the two versioned policy artefacts. `domain/bands.py` holds the `RiskBand` enum and its ordering; `domain/template_version_validator.py` parses risk-policy and template-version definitions (JSON dicts, decimals as strings) into frozen dataclasses and returns a list of violations for publish validation. The canonical v1 definitions (and the AC-10.1 / AC-10.5 v2 variants) are provided as test fixtures so later stories never re-type policy numbers.

## Acceptance criteria

1. **Template sum violation (AC-10.4, AC-02.4).** `validate_template_version(defn, active_asset_classes)` on the v1 template definition with AGGRESSIVE `GOLD = "7.51"` returns a violation whose text contains `AGGRESSIVE` and `sum=100.01`. The unmodified v1 template definition and the AC-10.5 v2 variant (MODERATE 45.00/40.00/10.00/5.00) return no violations.
2. **Template structural rules (AC-10.4).** Each of the following yields at least one named violation: a missing band; a missing or extra (inactive) asset class in a band; a value with 3 dp (`"10.005"`); a value outside [0.00, 100.00]; a horizon-rule gap (`H_60_83.min_months = 61`) or overlap; `shift` that is neither `"ALL"` nor a decimal in [0.00, 100.00]; `from == to`; `drift_threshold_pct` of `"0.00"` or `"50.01"`; a JSON number (non-string) for any decimal field.
3. **Risk policy rules (AC-10.1, AC-10.4).** `validate_risk_policy(defn)` returns no violations for v1 and for the AC-10.1 v2 variant (MODERATE 12–19, AGGRESSIVE 20–28). It returns a violation for each of: 5 questions; duplicate question code; non-contiguous orders; a question with 1 or 7 options; option points of 11 or -1; a band gap (MODERATE 13–20); last `max_score` 27 when the max achievable is 28; bands out of order; a cap referencing an unknown question, option or band.
4. **Band ordering and purity (AC-01.4, AC-01.3).** `RiskBand` has exactly CONSERVATIVE, MODERATE, AGGRESSIVE with `CONSERVATIVE < MODERATE < AGGRESSIVE` and `min_band(AGGRESSIVE, MODERATE) == MODERATE`. Both modules import only stdlib + `app.domain.*`; `tests/architecture/test_domain_has_no_framework_imports.py` passes and branch coverage of both modules is 100%.

## Produces
