## Description

Two pure domain modules. `domain/goal_horizon_policy.py` computes completed calendar months between dates, selects the horizon rule from a template version's rules, and picks the primary goal. `domain/allocation_template_policy.py` implements `recommend(band, template_version, horizon_months) -> Allocation`, applying the EQUITY shift (`min(rule_shift, EQUITY)` or ALL) and re-validating the exact-100.00 invariant via the existing `allocation/templates.validate_allocation`.

## Acceptance criteria

1. **Horizon month counting (AC-04.5, AC-04.1, AC-04.3).** With `as_of = 2026-01-31`: `horizon_months` to 2026-02-28 = 0, to 2027-01-31 = 12, to 2025-12-01 = 0. With `as_of = 2026-01-15`: to 2030-01-15 = 48, to 2028-06-30 = 29.
2. **Rule selection (AC-02.3, AC-04.2).** For TEMPLATE_V1 rules: months 0 and 11 → `H_0_11`; 12 and 35 → `H_12_35`; 36 and 59 → `H_36_59`; 60 and 83 → `H_60_83`; 84 and 240 → `H_84_PLUS`; `None` (no goal) → `NO_GOAL`.
3. **Worked examples and per-band templates (AC-04.2, AC-02.1, AC-02.2).** `recommend` reproduces every row of recommendation §2.3 exactly (MODERATE/120 → 50.00/35.00/10.00/5.00; MODERATE/48 → 30.00/55.00/10.00/5.00; AGGRESSIVE/24 → 45.00/45.00/7.50/2.50; CONSERVATIVE/24 → 0.00/80.00/10.00/10.00; AGGRESSIVE/6 → 0.00/15.00/7.50/77.50), and with no goal returns the §2.1 rows (CONSERVATIVE 20.00/60.00/10.00/10.00, MODERATE 50.00/35.00/10.00/5.00, AGGRESSIVE 75.00/15.00/7.50/2.50) with rule `NO_GOAL`.
4. **Sum invariant sweep (AC-02.3).** For every band × months in {0, 1, 11, 12, 35, 36, 59, 60, 83, 84, 240}, the allocation has exactly one entry per asset class, every `target_pct` is ≥ 0.00 with 2 dp, and the sum equals `Decimal("100.00")` exactly.
5. **Invariant guard (AC-02.4).** `recommend` on a template whose MODERATE row sums to 99.99 raises `AllocationSumError`.
6. **Primary goal and determinism (AC-04.3, AC-04.4).** `primary_goal([A(priority 2, 2040-01-01), B(priority 1, 2028-06-30)])` returns B; ties fall back to earliest `target_date`, then earliest `created_at`; an empty list returns `None`. Two calls with equal inputs return equal `Allocation` objects. Both modules are stdlib-only with 100% branch coverage.

## Produces

- `goal_horizon_policy.horizon_months`, `select_rule`, `primary_goal`; `allocation_template_policy.recommend` and the `Allocation` value object - **consumed by E3-S2**.
