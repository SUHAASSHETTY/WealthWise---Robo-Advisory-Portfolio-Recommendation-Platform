# WealthWise — Robo-Advisory & Portfolio Recommendation Platform

A rule-based robo-advisory platform providing risk profiling, deterministic portfolio recommendation, goal tracking, and drift-based rebalancing for retail investors, built agent-first on the Claude Harness Engine.

> **Note:** All changes flow through feature branches merged into `main` with `git merge --no-ff`. Direct commits to `main` are blocked by a local pre-commit hook.
